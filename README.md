# Library Management System

## Overview

This project is a console-based Library Management System developed in C++ using Object-Oriented Programming concepts.

The system helps manage books and library operations such as adding books, issuing books, returning books, and searching books by title or author.

## Features

* Add New Book
* Display Books
* Search Book by Title
* Search Book by Author
* Issue Book
* Return Book
* Menu Driven Interface

## Technologies Used

* C++
* Object-Oriented Programming
* File Handling

A functional application that enables book addition, issue and return processing, and search by title or author for streamlined library operations.
